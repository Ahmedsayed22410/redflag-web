# Red Flag Tracker — web

Desktop/browser version of the Red Flag Tracker. It uses the same Firebase project as the Android app,
so changes appear live on every phone and browser. Sign in with Google; access is the same as in the app
(owner approves each person, members change only their own sites).

Website: https://ahmedsayed22410.github.io/redflag-web/

This repo holds only the page. The data lives in Firebase, protected by sign-in and the Firestore rules.
